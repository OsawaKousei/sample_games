# Signal Arcade

React + Vite をベースにした、個別に起動できる3つのブラウザゲームです。

## 起動

Node.js **22.12以上**を使用してください。ワークスペース直下で実行します。

```sh
npm install

npm run gomoku    # 五目並べ
npm run shooter   # 縦型STG「STARFALL」
npm run survivor  # 3Dサバイバル「WILDBLOOM」
```

いずれも **http://localhost:3000** で起動します。同じポートを使用するため、切り替えるときは実行中のサーバーを `Ctrl+C` で終了してください。ポート使用中は別ポートへ自動変更せずエラーにします。

依存パッケージはnpm workspacesで管理します。初回の `npm install` はルートで1回だけ必要です。

## ゲーム

### gomoku / 五目並べ

15×15の盤面で、あなたが黒・先手、AIが白・後手です。縦・横・斜めに5つ以上連続すると勝利する自由ルールです（禁手・三三・四四の制限なし）。

- **Easy**：即勝ち・防御に加え、三や四を作る・止める基本の攻防を優先。通常は評価の近い上位3候補から重み付きで選びます。
- **Normal**：連続形、開放端、5マスの窓に含まれる脅威を評価。
- **Hard**：反復深化・Alpha-Beta/PVS探索、局面キャッシュ、差分評価を使用。両端の空いた四・飛び四・複数方向の脅威を評価し、通常最大12手先、四への応手などはさらに最大10手読み延長します。ルート24候補・内部14候補を基本とし、重要な攻防の候補は枠外でも残します。思考予算6,200msで、完了した深さの最善手を採用。着手表示まで7秒以内が目標です（端末性能やブラウザの負荷で変動します）。
- Hardの序盤は事前探索済みの応手表を使用します。中央への初手、中央から2マス以内の黒の2手目、および続く代表的な分岐を白の3手目まで収録。回転・反転を同一局面として扱い、盤面全体が一致する場合だけ即座に応手を返します。端からの開始や未収録の分岐は通常探索へ戻ります。データは自由ルールの現行Hardで生成したもので、連珠の定石集ではありません。再生成は `node gomoku/scripts/generate-opening-book.mjs`（各局面最大6.2秒、全体で数分）。
- AIはWeb Workerで実行します。「思考をのぞく」がONのときだけ候補位置と評価値を表示します。数値は勝率ではありません。
- 履歴ボタン・棋譜スライダーで過去の盤面を確認できます。「最新へ」で対局に戻ります。「一手戻す」は人間の手番まで巻き戻し、その先の棋譜を破棄します。
- 難易度の変更は新しい対局になります。

**対戦AIはローカルな探索アルゴリズムです。制作支援のCodexとは別のもので、対戦中に生成AI APIを呼び出しません。**

### shooter / STARFALL

ReactのUIとPhaserの描画を組み合わせた縦型STGです。通常ウェーブはSTAGE 1が25秒、STAGE 2が48秒、STAGE 3が66秒。その後のボス戦を含め、全3ステージを突破するとクリアです。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー |
| ショット | Space / Z（初期状態は自動射撃ON） |
| 低速移動 | Shift |
| ボム | X / 画面のボタン |
| 一時停止・再開 | P / Esc / 画面のボタン |
| タッチ移動 | 盤面をドラッグ |

- 体力5、被弾後1.5秒の無敵時間。自機中央の白い点が当たり判定です。
- 敵5体撃破ごとにアイテム出現。射撃は3段階、回復アイテムもあります。
- ボムは弾消し・範囲攻撃・2秒無敵。ステージ突破で体力とボムを1回復。
- 通常移動は360px/秒、低速移動は155px/秒。当たり判定は中央の半径3pxで、高速弾も移動経路で衝突を判定します。
- STAGE 1は導入。STAGE 2・3は固定の出現順と攻撃手順を持ち、誘導・切り返し・先回り・早期撃破によるパターン攻略を要求します。
- 同じ丸弾の配置・発射間隔・速度変化で、花弁、対向螺旋、交差列、自機狙い連射、移動する隙間、掃射、加速する輪、斜めの格子を構成します。攻撃前に発射位置や狙い、壁の隙間を予告します。
- ボスは順に2・3・4フェーズ。後半は各フェーズに専用の攻撃順を持ち、長引いた場合は順序と左右を変えて展開します。フェーズ切替時とボム使用時には、発射待ちの攻撃も消去します。
- パーティクル、画面振動、スクロール背景、ステージごとの背景・敵構成を実装。
- リザルトはスコア、撃破数、命中率を表示。自己ベストをブラウザに保存。

### survivor / WILDBLOOM

Three.jsで描画する、斜め上から見下ろした低ポリゴン3Dサバイバルです。45秒×3フェーズ、合計**2分15秒**を生存するとクリアです。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー |
| 回避ステップ | Space（クールダウン3.5秒） |
| 攻撃 | 射程内の近い敵へ自動射撃 |
| 一時停止・再開 | P / Esc / 画面のボタン |
| タッチ操作 | 左の移動パッド・右の回避ボタン |

- 起伏のあるフィールドと3種類の追跡敵。フェーズごとに敵の速度・種類・密度が変化。
- 経験値は近づくと吸着。レベルアップで3択の強化を提示。
- フィールドには開始6秒後、その後11秒ごとに琥珀色の強化結晶がランダム出現。
- 攻撃間隔、移動速度、射程、攻撃力、周回衛星、同時攻撃数、回復の7種類から選択。
- 強化選択中はゲーム時間が停止します。敵・アイテム・提示される強化はランダムです。
- 撃破数の自己ベストをブラウザに保存。リトライ時はビルドを初期化。
- WebGL 2を使用します。描画できない場合は対応ブラウザ・ハードウェアアクセラレーションを確認してください。

STGと3Dサバイバルは、ウィンドウがフォーカスを失うと自動で一時停止します。

## 構成

```text
package.json             # 各ゲームの起動・全体のビルドとテスト
package-lock.json        # 依存関係の固定
arcade.css               # 共通スタイル
playwright.config.js     # ブラウザテスト設定
├── gomoku/
│   └── src/             # React UI、AI、Web Worker、テスト
├── shooter/
│   └── src/             # React UI、Phaser描画、独立したゲームモデル、テスト
└── survivor/
    └── src/             # React UI、Three.js描画、独立したゲームモデル、テスト
```

描画とゲームルールを分離し、戦闘・遷移・勝敗のロジックをNode.jsから検証できる構成です。図形と3Dモデルはコードで生成しています。画像・音声素材やAPIキーは不要です。フォントはGoogle Fontsを読み込み、取得できない場合はシステムフォントへフォールバックします。BGM・効果音は実装していません。

## 検証とビルド

```sh
npm test                 # AI・戦闘・強化・ステージ遷移のロジックテスト
npm run build            # 3作品の本番ビルド。各ディレクトリの dist/ に出力

# 初回のみ、テスト用ブラウザを取得
npx playwright install chromium
npm run test:browser     # デスクトップ・モバイル幅の操作確認
```

ブラウザテストは3100・3101・3102番ポートで専用サーバーを自動起動・終了します。スクリーンショットは `test-results/` に出力します。Phaser / Three.jsを含むビルドではViteの500kB超のチャンク警告が出ますが、ビルド自体は成功します。

実装に使用したAPIの参考： [Phaser Scene](https://docs.phaser.io/api-documentation/class/scene)、[Phaser Scale](https://docs.phaser.io/api-documentation/namespace/scale)、[Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer)。
