# STAGE 3

道中は8秒。冒頭の波打つ高密度弾列だけを残し、レーザー＋自機狙いと左右の櫛状弾列の区間は削除した。0〜6秒に弾列を出し、6〜8秒は残った弾を抜ける時間。8秒で道中の敵・弾を消去し、そのままボスへ進む。発射源を倒すと、その敵の担当する丸弾を止められる。

低速移動は90px/秒、通常移動は360px/秒。細い隙間では低速、大きく位置を変える際には通常移動を使う。

## 回避と難易度の検証

- フェーズ1：円環を90方向から78方向へ変更し、角度の間隔を約15%拡大。発射間隔も0.17秒から0.19秒へ広げた。交互の半歩ずらし、7拍ごとの切れ目、弾速は維持する。
- フェーズ2：自機の周囲に22方向×3層の赤い輪、11方向×2層の青い輪を2.4秒周期で置く。0.15秒後に外向きに動き、赤弾だけが出現から1.6秒後の自機へ再照準する。青弾は外向きを保つ。輪の通常の隙間を早めに抜け、直角移動で追撃を外す。指定出口と旧中心への固定照準を廃止した。
- フェーズ3：四隅の弾塊が時間差で開く構成へ差し替え。6秒周期で4か所に48方向×3層の丸弾を配置する。待機時間は0.65 / 1.10 / 1.55 / 2.00秒。先に開く場所を周期ごとに一つずらし、空いた弾塊の内側へ移動して次の展開に備える。1波576発、寿命5.7秒なので前波と次波の弾数が積み上がらない。
- フェーズ4：赤36→32方向・0.25→0.28秒間隔、紫は片側9→8方向・0.48→0.54秒、青48→42方向・0.95→1.05秒、黄24→21方向・0.8→0.9秒へ調整。紫の扇の範囲は保ち、全色で隙間を広げた。弾速と時間・体力による重なりの増加は維持する。
- 既知の回避経路：フレームごとの座標指定を廃止。フェーズ2は最短400msの入力保持で40秒、フェーズ3は最短500msの保持で32秒。時刻の一律ずれ−100 / −50 / 0 / +50 / +100msと、開始位置の中央・左右上下4pxずれを組み合わせた各25条件を検証する。範囲外の失敗も[難易度評価](difficulty-evaluation.md)に残す。

ボスはフェーズ3でも左右移動を継続する。弾塊の配置はボスの位置に依存しない。フェーズ切替時は最大90px/秒の移動制限を保ち、ワープと準備停止を発生させない。フェーズ3の体力は720。
上記は実際のゲームロジックを使う自動リプレイの検証であり、人間の通しプレイによる評価ではない。

## 描画負荷

敵弾の光・色・白い芯を1枚のテクスチャに事前描画し、PhaserのBlitterでまとめて表示する。表示枠は再利用し、画面外の弾は描画だけ省く。描画上の省略は弾の動きや当たり判定に影響しない。移動経路の当たり判定は遠い弾を先に除外し、弾配列は更新と同時に詰め直す。

フェーズ2・3の今回の調整前に行った、2026-11-21のChromium / SwiftShader検証では、各フェーズの20秒時点の弾配置を固定し、60フレーム測定（先頭10フレーム除外）。ゲームループ開始から描画コマンド送信完了までのCPU側平均時間は次の通り。GPU完了時間や実機のFPSを保証する数値ではない。

| --- | ---: | ---: | ---: |
| 1 | 1,306 | 151.1ms | 1.0ms |
| 2 | 242 | 22.1ms | 0.8ms |
| 3 | 833 | 116.7ms | 0.9ms |

## ボスの参照元と解釈

東方紺珠伝の高難度弾幕を調べ、通常の丸弾だけで成立する4種類を選んだ。素材やコードは使用せず、下記の回避構造をこのゲームの画面・移動速度・当たり判定に合わせて実装している。ゲーム内のフェーズ名は `PHASE 1` などの番号のみ。

| フェーズ | 参照元 | このゲームでの構成 |
| --- | --- | --- |
| 1 | 純狐「震え凍える星」 | 隙間を交互に半歩ずらす連続円環。波の切れ目で切り返す。 |
| 2 | 純狐「地上穢の純化」 | 広がる赤い輪の隙間を抜け、再照準された自機狙いを直角移動で誘導する。青い輪は広がり続ける。 |
| 3 | 純狐「現代の神霊界」 | 四隅に配置した弾塊が順に開く。先に空いた内部へ入り、次の周期に向けて移動する。 |
| 4 | 純狐・純符「純粋な弾幕地獄」 | 中央の赤弾、左右の紫弾、高速の青弾、固定配置の黄弾が体力と時間に応じて重なる。 |

### フェーズ2・3の出典再確認（2026-11-21）

攻略Wikiの[「地上穢の純化」](https://wikiwiki.jp/thk/%E7%B4%BA/6#k9cf86d7)は、輪の拡大→全弾の自機狙い化→次の輪に対して直角に抜ける攻略を説明している。Lunaticではさらに外向きの青い輪が加わる。以前の実装は赤弾を出現時の位置へ固定照準し、指定された大きな出口を歩くだけになっており、この誘導の意味を失っていた。今回、後から行う再照準と赤／青の役割分担を復元した。輪の層数、半径、周期はこのゲームに合わせた変更であり、原作の数値を複製したものではない。

フェーズ3は「逢魔ガ刻」のワインダーから、[「現代の神霊界」](https://wikiwiki.jp/thk/%E7%B4%BA/6#qf8a2d6a)を参考にした四隅の弾塊へ差し替えた。出典では四隅の中弾が時間差で崩れ、展開前に一色の弾の中へ入る回避を説明している。このゲームでは普通の丸弾で同心の塊を作り、ランダムな崩れ方を固定の順番と速度に置き換える。発射順と次の退避場所を覚える独自の再構成であり、原作の完全再現ではない。

照合したのは攻略資料の記述であり、原作の映像・内部コード・当たり判定との完全一致を検証したわけではない。

参照：[東方Project攻略Wiki・Stage 6](https://wikiwiki.jp/thk/%E7%B4%BA/6)。巨大弾、月、曲線レーザーはボス戦に使用しない。

## デバッグ用URL

`npm run shooter` で起動し、[開始位置一覧](http://localhost:3000/debug)から選択する。各URLでは待機画面を表示し、「ゲーム開始」で戦闘を開始する。

- `/debug/stage/1`、`/debug/stage/2`、`/debug/stage/3`
- `/debug/boss/1/phase/1`〜`/debug/boss/1/phase/2`
- `/debug/boss/2/phase/1`〜`/debug/boss/2/phase/3`
- `/debug/boss/3/phase/1`〜`/debug/boss/3/phase/4`

シールド5、火力3、ボム3、スコア0、無敵なし、敵弾なしで開始する。ボスは選択したフェーズの体力を全量持ち、登場移動を省略する。「最初から」「もう一度プレイ」でも選択位置に戻る。通常と同じ被弾・ボム・フェーズ進行を使用するが、自己ベストは更新しない。

Viteの開発・プレビューサーバーではURLへ直接アクセスできる。別の静的ホストに配置する場合も、`/debug/*` を `index.html` に返すSPAフォールバックを設定する。
