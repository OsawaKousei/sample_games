# STAGE 3

道中は30秒。0〜8秒は波打つ高密度の弾列、8〜22秒は狭い縦レーザー区画と自機狙いの斜めレーザー・連射弾、22〜30秒は左右から交互に来る櫛状の弾列で構成する。発射源の敵を倒すと、その敵の担当する丸弾を止められる。レーザーは細線の予告、発射、消失の順に進み、太く光る間だけ当たり判定を持つ。

縦レーザーは64px間隔、2.4秒周期で位置をずらす。0.7秒の予告後に1.7秒発射する。区画内にいる間、左右から自機の旧位置を狙う斜めレーザーを重ねる。斜めレーザーは0.8秒予告し、その間に狙いから外れられる。丸弾は0.28秒ごとの7方向自機狙い。区画の中心付近で誘導し、横にずれて避け、縦レーザーの消失に合わせて次の区画へ移る。

## 描画負荷

敵弾の光・色・白い芯を1枚のテクスチャに事前描画し、PhaserのBlitterでまとめて表示する。表示枠は再利用し、画面外の弾は描画だけ省く。ボスの弾数・配置・速度・当たり判定の大きさは維持する。移動経路の当たり判定は遠い弾を先に除外し、弾配列は更新と同時に詰め直す。

2026-11-21のChromium / SwiftShader検証では、各フェーズの20秒時点の弾配置を固定し、60フレーム測定（先頭10フレーム除外）。ゲームループ開始から描画コマンド送信完了までのCPU側平均時間は次の通り。GPU完了時間や実機のFPSを保証する数値ではない。

| フェーズ | 弾数 | 変更前 | 変更後 |
| --- | ---: | ---: | ---: |
| 1 | 1,306 | 151.1ms | 1.0ms |
| 2 | 242 | 22.1ms | 0.8ms |
| 3 | 833 | 116.7ms | 0.9ms |
| 4 | 788 | 112.3ms | 0.8ms |

## ボスの参照元と解釈

東方紺珠伝の高難度弾幕を調べ、通常の丸弾だけで成立する4種類を選んだ。素材やコードは使用せず、下記の回避構造をこのゲームの画面・移動速度・当たり判定に合わせて実装している。ゲーム内のフェーズ名は `PHASE 1` などの番号のみ。

| フェーズ | 参照元 | このゲームでの構成 |
| --- | --- | --- |
| 1 | 純狐「震え凍える星」 | 隙間を交互に半歩ずらす連続円環。波の切れ目で切り返す。 |
| 2 | 純狐「地上穢の純化」 | 自機の旧位置を囲む三重の輪。隙間から外へ出た後、向かってくる弾を誘導する。 |
| 3 | ヘカーティア・異界「逢魔ガ刻」 | 四方向の厚い弾列が回転し、切れ目を挟んで回転方向が反転する。開いた領域に沿って大きく動く。 |
| 4 | 純狐・純符「純粋な弾幕地獄」 | 中央の赤弾、左右の紫弾、高速の青弾、固定配置の黄弾が体力と時間に応じて重なる。 |

参照：[東方Project攻略Wiki・Stage 6](https://wikiwiki.jp/thk/%E7%B4%BA/6)、[東方Project攻略Wiki・Extra](https://wikiwiki.jp/thk/%E7%B4%BA/EX)。巨大弾、月、曲線レーザーはボス戦に使用しない。

## デバッグ用URL

`npm run shooter` で起動し、[開始位置一覧](http://localhost:3000/debug)から選択する。各URLでは待機画面を表示し、「ゲーム開始」で戦闘を開始する。

- `/debug/stage/1`、`/debug/stage/2`、`/debug/stage/3`
- `/debug/boss/1/phase/1`〜`/debug/boss/1/phase/2`
- `/debug/boss/2/phase/1`〜`/debug/boss/2/phase/3`
- `/debug/boss/3/phase/1`〜`/debug/boss/3/phase/4`

シールド5、火力3、ボム3、スコア0、無敵なし、敵弾なしで開始する。ボスは選択したフェーズの体力を全量持ち、登場移動を省略する。「最初から」「もう一度プレイ」でも選択位置に戻る。通常と同じ被弾・ボム・フェーズ進行を使用するが、自己ベストは更新しない。

Viteの開発・プレビューサーバーではURLへ直接アクセスできる。別の静的ホストに配置する場合も、`/debug/*` を `index.html` に返すSPAフォールバックを設定する。
